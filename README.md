# elimikabure - Free Education for Every African Child

**elimikabure** (meaning "free education" in Swahili) is a comprehensive educational platform designed to democratize access to quality education for Kenyan and African students. Our mission is to break down barriers and create opportunities by consolidating educational resources, scholarships, free courses, and study materials in one centralized platform.

## 🌍 Vision

To make quality education accessible to every African child, regardless of their economic background, by providing a one-stop platform for educational opportunities and resources.

## ✨ Features

### 🎓 Scholarships
- Comprehensive database of fully-funded and partial scholarships
- Scholarships for all educational levels (primary, secondary, undergraduate, graduate)
- Detailed eligibility criteria and application deadlines
- International and local scholarship opportunities

### 📚 Free Courses
- Curated collection of free online courses from top universities
- Courses from platforms like Coursera, edX, FutureLearn, and more
- Certificate-bearing courses available
- Multiple categories: Computer Science, Finance, Health, Marketing, etc.

### 📖 Study Materials
- Textbooks aligned with Kenyan curricula (8-4-4 System, CBC)
- International curriculum resources (Cambridge IGCSE, A-Level)
- Past examination papers with marking schemes
- Study notes and revision materials
- Digital literacy resources

### 🤝 Community Features
- Student forums and discussion groups
- Resource sharing capabilities
- Mentorship programs
- Success stories and testimonials

### 💼 Career Guidance
- Career development resources
- Internship opportunities
- Professional skill development
- Interview preparation materials

## 🚀 Getting Started

### Prerequisites

- Node.js 18.0 or later
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/elimikabure.git
cd elimikabure
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## 🤔 Why elimikabure?

Education is a fundamental right, yet millions of African students face barriers to quality education due to:
- Financial constraints
- Limited access to information
- Scattered resources across multiple platforms
- Lack of guidance and mentorship

elimikabure addresses these challenges by:
- Centralizing educational opportunities
- Providing free access to all resources
- Creating a supportive community
- Offering career guidance and mentorship
